# KnowGacha ― 脳ガチャ ―

一日一つ、名前しか知らなかった世界を知る。Expo SDK 58 / React Native / TypeScript による最初の試作品です。SwiftUI・SwiftDataではなく、WSL2とiPhoneのExpo Goを優先します。

## 起動

```bash
npm ci
npx expo start --go --tunnel --clear
```

WSL2 UbuntuとiPhoneの組み合わせでは、トンネル接続で起動できることを確認済みです。初回はExpo CLIからトンネル用ツールの導入を求められる場合があります。

1. トンネルの準備が完了し、QRコードが表示されるまで待ちます。
2. iPhoneのカメラで、今回表示されたQRコードを読み取り、Expo Goで開きます。
3. 動作確認中は、WSLの開発サーバーを起動したままにします。

トンネル接続にはPC・iPhone両方のインターネット接続が必要です。LAN接続を試す場合は、同じWi-Fiに接続して `npx expo start --go` を実行します。

## 起動時のエラーを確認する

### Expo Goで「The request timed out」と表示される

`Metro: exp://172.28.252.251:8081` のようにWSL内部のIPアドレスが表示されている場合は、LAN接続で起動しています。このアドレスへiPhoneから接続できず、タイムアウトする場合があります。今回の環境では、トンネル接続に切り替えて解消しました。

1. ターミナルで `Ctrl+C` を押し、開発サーバーを停止します。
2. `npx expo start --go --tunnel --clear` で起動し直します。
3. Expo Goを一度終了し、新しく表示されたQRコードから開きます。Expo Goの履歴にある古い接続先は使いません。

まだ接続できない場合は、起動コマンドと、`Metro:` の接続先・トンネル起動時のエラーを確認してください。

### Webのビルドで依存が見つからない

`Web Bundling` はブラウザ向けのビルドです。iPhoneのネイティブ動作確認では、ターミナルの `w` キーやブラウザ表示ではなく、QRコードからExpo Goで開いてください。

`Unable to resolve "react-native-web/dist/index"` が出る場合は、最新の依存を入れ直してキャッシュをクリアします。

```bash
npm ci
npx expo start --go --tunnel --clear
```

Webプレビュー用の `react-native-web` も依存に含めています。

## iPhoneでの確認

1. ホームのアプリ名・説明・「今日の一語を開く」を確認する。
2. 開封し、名称・導入文・短い解説・深掘り本文を読む。
3. 戻って「今日の一語を読み返す」を押し、同じ語が表示されることを確認する。連打しても履歴が増えないことも確認する。
4. Expo Goを終了し、同じプロジェクトを開き直す。今日の語と開封履歴が復元されることを確認する。
5. ホームの開発用「翌日扱いにする」を押し、新しい未開封語が出ることを確認する。開発用の日付差分も再起動後に復元される。
6. 3語すべて開封する。当日は3語目を再閲覧でき、さらに翌日へ進めると全件開封の案内が出る。
7. 「開封履歴を見る」から全3語を読み返す。
8. 「進捗を初期化する」でキャンセルを試し、次に実行する。履歴・今日の語・開発用日付が初期状態に戻り、再起動後も維持される。
9. 可能なら現地の午前0時をまたいで起動を継続、またはバックグラウンドから復帰し、新しい日の表示になることを確認する。

開発用ボタンは `__DEV__` のときだけ表示・実行できます。製品モードでは開発用日付差分を無視します。トンネル経由のiPhone接続・起動は確認済みです。上記の各機能については、この手順で別途確認してください。

## UI/UX試作の確認

- 「今日」と「知識の地図」を下部タブで切り替えられます。
- 未開封語を開くとカプセルが開き、結果カードから解説または地図へ進めます。保存後に演出を始め、「演出をスキップ」でも同じ語が表示されます。
- 同日の再訪は再抽選・再演出せず読み返せます。新しい演出を見る場合は開発用の「翌日扱いにする」を使ってください。
- 地図は開封した教材とその周辺語だけを表示します。ノード・線を押すと下部パネルに説明が出ます。
- ドラッグ・ピンチ・＋／−で移動と拡縮。「全体」でまとまりを俯瞰し、「選択に戻る」で復帰できます。
- 「一覧」でも同じ教材・周辺語・関係へ到達できます。周辺語の閲覧で開封数は増えません。
- 解説の「この言葉のまわり」から、その関係を選択した地図へ移動できます。

新機能のiPhone実機確認は未実施です。詳細な確認項目は設計書の実装記録を参照してください。

## 構成・保存

- `src/app/`: Expo Routerのホーム・履歴・解説画面
- `src/data/graph.ts`: 周辺語・関係・固定配置・カードの印と色。
- `src/components/Capsule.tsx`: 保存後の開封演出と軽い振動。
- `src/components/GraphCanvas.tsx`: 地図と移動・拡縮。
- `src/data/keywords.ts`: 光電融合・エスノグラフィー・シュルレアリスムの独自の試作用原稿。公開用の校閲・出典確認は未実施。
- `src/state/progress.ts`: 現地日付、未開封語のランダム選出、保存形式の検証
- `src/state/ProgressProvider.tsx`: AsyncStorageによる復元と保存。開封日と履歴を一つのJSONとして保存し、保存成功後に表示を更新。並行操作を防止。

開封は現地の暦日ごとに一回で、未開封日の権利は蓄積しません。端末時計変更への厳密な対策はありません。保存はこの端末のアプリ領域のみで、アンインストール後の復元・機種間同期・書き出しは今回の範囲外です。読み込み失敗時はデータを上書きせず再試行を表示します。

課金・通知・バックエンドは含みません。知識の地図は3教材と6周辺語の小規模な固定配置です。企画全体は `docs/proposal.md` を参照してください。
