# KnowGacha ― 脳ガチャ ―

一日一つ、名前しか知らなかった世界を知る。Expo SDK 58 / React Native / TypeScript による最初の試作品です。SwiftUI・SwiftDataではなく、WSL2とiPhoneのExpo Goを優先します。

## 起動

```bash
npm ci
npx expo start --go --tunnel --clear
```

WSL2 UbuntuとiPhoneの組み合わせでは、トンネル接続で起動できることを確認済みです。初回はExpo CLIからトンネル用ツールの導入を求められる場合があります。

1. トンネルの準備が完了し、QRコードが表示されるまで待ちます。
2. iPhoneのカメラで、今回表示されたQRコードを読み取り、Expo Goで開きます。
3. 動作確認中は、WSLの開発サーバーを起動したままにします。

トンネル接続にはPC・iPhone両方のインターネット接続が必要です。LAN接続を試す場合は、同じWi-Fiに接続して `npx expo start --go` を実行します。

## 起動時のエラーを確認する

### Expo Goで「The request timed out」と表示される

`Metro: exp://172.28.252.251:8081` のようにWSL内部のIPアドレスが表示されている場合は、LAN接続で起動しています。このアドレスへiPhoneから接続できず、タイムアウトする場合があります。今回の環境では、トンネル接続に切り替えて解消しました。

1. ターミナルで `Ctrl+C` を押し、開発サーバーを停止します。
2. `npx expo start --go --tunnel --clear` で起動し直します。
3. Expo Goを一度終了し、新しく表示されたQRコードから開きます。Expo Goの履歴にある古い接続先は使いません。

まだ接続できない場合は、起動コマンドと、`Metro:` の接続先・トンネル起動時のエラーを確認してください。

### Webのビルドで依存が見つからない

`Web Bundling` はブラウザ向けのビルドです。iPhoneのネイティブ動作確認では、ターミナルの `w` キーやブラウザ表示ではなく、QRコードからExpo Goで開いてください。

`Unable to resolve "react-native-web/dist/index"` が出る場合は、最新の依存を入れ直してキャッシュをクリアします。

```bash
npm ci
npx expo start --go --tunnel --clear
```

Webプレビュー用の `react-native-web` も依存に含めています。

## iPhoneでの確認

1. Mapから「最初の知識をひらく」または「今日の知識をひらく」を押す。
2. キャラクターの演出後、Mapの新しい知識と一言プレビューを確認。「読む」から記事をスクロールして参考資料まで読む。
3. 記事末尾の「Mapで見る」で対象の語へ移動し、選択プレビューの「読む」から再読する。戻ると元のMapへ戻る。
4. 特典がある場合は記事末尾の「特典でもうひとつ」で追加開封する。初期10回の設定は維持し、10回後も翌日の1回で続けられる。
5. Mapの「知識一覧」で日本語・英語名や分野を検索して読み返す。記事から戻ると検索状態を保持する。
6. 再起動して履歴とMap位置の保持を確認する。
7. 設定の「検証メニュー」で初期10回への初期化のキャンセル・実行、開発時のみ表示する「翌日扱いにする」を確認する。
8. 日付変更・背景復帰時の当日分表示を確認する。

開発用ボタンは `__DEV__` のときだけ表示・実行できます。製品モードでは開発用日付差分を無視します。トンネル経由のiPhone接続・起動は確認済みです。上記の各機能については、この手順で別途確認してください。

## アイコンの残り回数（iOS）

Map右上の設定 →「アイコンに残り回数を表示」をオンにし、通知を許可すると、ホーム画面のアイコンへ開封可能回数を表示します。貯まった日次分＋初回特典で数え、0回なら消えます。開封成功後に更新し、翌日分は音や本文のない予約で更新します。毎日のリマインダーとは別にオン/オフできます。OSの通知設定で「バッジ」も有効にしてください。

未設定時は初期オンです（OSの許可が必要）。保存済みのオン/オフは保持します。WebとAndroidは今回の数値表示の対象外です。iOSの予約反映は端末状態によって遅れる場合があります。新しいネイティブ依存はなく、1.0.4の互換更新です。実際のアイコン表示と背景での日付変更は実機確認待ちです。[設計と検証](docs/remaining-draw-badge.md)を参照してください。

## UI/UX試作の確認

表示言語は日本語と英語に対応し、初回は端末の優先言語（日本語以外は英語）を使用します。Map右上の歯車 →「設定」→「言語 / Language」から変更でき、再起動後も選択を保持します。切り替えても開封履歴・残り回数は共通です。参考リンクには資料の言語を添え、原典のURLを保ちます。[言語対応の記録](docs/languages.md)を参照してください。既存のプレビューアプリでは、ネイティブ依存を含む1.0.2へ一度上書きインストールが必要です。

- Mapを唯一のホームとし、下部タブを廃止しました。左下の「今日の知識」と「ガチャをひく（あとN回）」を独立した面とボタンで表示します。
- 開封演出の後はMapで新しい知識へ移動し、一言プレビューを表示します。「読む」から共通記事で全文・関係・参考資料を読めます。
- Mapのノード選択ではカメラを動かさず、小さなプレビューから「読む」。周辺概念・線の説明はシートで確認できます。
- 記事の「Mapで見る」は対象へ移動し、通常の「戻る」は元の場所へ戻ります。＋／−は1回で1.6倍／その逆、全体表示も利用できます。
- 知識一覧は開封履歴と統合し、新しい順・日付ごとに表示します。未開封教材は一覧や検索に表示しません。
- 知識のゆっくりした動き、ピンチ操作、位置保存、初回特典・当日分の権利管理は維持しています。

現行設計と検証は[繰越・Map開封・通知初期値](docs/daily-rollover-map-reveal.md)を参照してください。


アプリアイコンは、控えめな脳のしわ・半目・短い足のカプセルです。起動時も同じキャラクターが小さく揺れてからMapへ進みます。Mapの初回案内と開封でも同じキャラクターを使い、揺れてから上下に開いて知識を表示します。動きを減らす設定では開封の動きを省きます。[採用画像と起動](docs/brain-capsule-brand.md)、[開封演出と動画](docs/mascot-gacha-animation.md)を参照してください。

OSの明暗設定に合わせて配色が変わります。対応iOSのMap操作バーではLiquid Glassを使い、非対応環境・透明度を下げる設定では不透明に表示します。本文は常に不透明な背景です。

#9のiPhone／Android実機確認は未実施です。Web確認・ネイティブバンドル生成と、実機の操作感・触覚・ガラス確認は区別しています。[UI統合の設計・検証記録](docs/native-ui-integration.md)を参照してください。SDK 58対応のExpo Goで確認できます。既存の開発・リリースビルドを使う場合は、追加したネイティブ依存を含むビルドを作り直してください。

Mapホームの設計と検証結果は [docs/map-home.md](docs/map-home.md) に記録しています。#8の実機確認は未実施です。

## 構成・保存

- `src/app/`: Expo Routerのホーム・履歴・解説画面
- `src/data/graph.ts`: 周辺語・関係・固定配置・カードの印と色。
- `src/components/Capsule.tsx`: 保存後の開封演出。触覚は保存成功時にsrc/ui/feedback.tsから実行。
- `src/components/GraphCanvas.tsx`: 地図と移動・拡縮。
- `src/data/keywords.ts`: 抽選対象30件と履歴互換用4件の教材カタログ。新規・改稿の日英原稿は`src/data/curated-knowledge.ts`と`src/i18n/content-en.json`。参考資料付きの独自原稿で、公開前の校閲は別途必要。
- `src/state/progress.ts`: 現地日付、未開封語のランダム選出、保存形式の検証
- `src/state/ProgressProvider.tsx`: AsyncStorageによる復元と保存。開封日と履歴を一つのJSONとして保存し、保存成功後に表示を更新。並行操作を防止。

日次権利は現地の暦日ごとに一回分増え、未使用分は貯まります。0回の状態から3日経過すると3回分を同じ日に使えます。初回特典も繰り越します。開始日を最初の起動時に保存し、旧v1/v2は履歴を保持してv3へ移行します。旧データは最古の開封日から未使用の日次分を引き継ぎます。v3を読めない旧コードへの単純ロールバックはできません。端末時計変更への厳密な対策はありません。保存はこの端末のアプリ領域のみで、アンインストール後の復元・機種間同期・書き出しは今回の範囲外です。読み込み失敗時はデータを上書きせず再試行を表示します。

課金・バックエンドは含みません。抽選対象は30教材です。写真・コラージュ・ユーザーリサーチ・光ファイバーは新規抽選から外し、周辺概念と過去の履歴から参照できます。履歴・残り回数を初期化せず更新します。[30教材の選定・移行記録](docs/curated-thirty.md)を参照してください。企画全体は `docs/proposal.md` を参照してください。

Map右上の設定から「毎日のリマインダー」をオンにすると、選んだ時刻に未開封のガチャをお知らせします。未設定時は初期オン・8:00で、保存データ読込後にOSの通知許可を一度求めます。保存済みのオフ・設定時刻は保持します。当日の開封後・全教材の取得後は通知を止めます。日本語・英語に対応し、通知を押すとMapへ移動します。記事を読んでいる最中は読書画面を保ちます。「5秒後にテスト通知」で受信を確認できます。Webでは通知を利用できません。[通知の仕様と検証](docs/daily-reminders.md)を参照してください。

通知は1.0.3以降のiOS Previewビルドで利用できます。**今回のアイコン・起動画面を反映するには1.0.4の新ビルドの上書きインストール**が必要です。通常の更新だけではホーム画面アイコンは変わりません。アプリを削除する必要はなく、取得履歴を引き継げます。[新ビルドの手順](docs/eas-update.md)を参照してください。

## 知識グラフの件数別デモ（開発用）

Expo Go等の開発モードで、Map右上の設定 →「検証メニュー」→「知識グラフのデモ」を開きます。5・10・50・100・500件を切り替え、5〜10件は「次の1件を追加」で成長を追えます。ノードから関係の理由・出典を読み、一覧や周辺表示で探索できます。「デモを終了」で実際のMapへ戻ります。実際の取得履歴は変更しません。

50・100・500件には架空の規模検証用データを含みます。最初の30件は通常教材を共有します。学習教材ではありません。設計・出典・確認画像・未検証事項は[知識グラフデモの記録](docs/knowledge-graph-demo.md)を参照してください。
