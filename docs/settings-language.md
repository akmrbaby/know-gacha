# 言語切り替えの配置修正（2026-11-09）

## 実装前の設計

Gacha下部の履歴・検証メニューの並びに日本語／Englishが置かれており、アプリ全体の設定として見つけづらいとの指摘。言語選択を独立した設定画面へ移し、Map・Gachaの右上に共通の歯車の入口を置く。

設定画面は既存のStackの`/settings`として追加する。タイトルは日本語「設定」・英語「Settings」。中に「言語 / Language」と日本語・Englishの2行を表示し、現在の選択にチェックを付ける。行全体を押せ、48点以上の領域と文字拡大・明暗の配色を保つ。言語名は常に各言語の名前のまま表示する。

Gacha下部の切り替えは撤去。Mapの一覧ボタンは保持し、その右に設定を置く。Gachaはブランド表示の右に設定を置き、履歴・残数・開封操作から独立した入口にする。空のMap、保存エラー時にも設定を開ける。

言語の保存キー・端末の初期言語・変更失敗時の動作は既存のI18nProviderを使用する。設定で切り替えるとタイトルと直前の画面にも反映し、標準の戻る操作で元のMap/Gachaへ戻る。履歴・権利・Mapの選択とカメラ位置は変更しない。設定に無関係な項目を追加せず、ネイティブ依存・設定も変更しない。

## 受け入れ条件

- Map・Gachaの右上に同じ設定アイコンがあり、Gacha本文に言語ボタンがない。
- 日英の切り替え、選択のチェック、再起動後の復元、保存失敗と再試行を確認する。
- 戻ると元のタブと取得済みの知識・権利・Mapの位置が維持される。
- 小画面・暗色・文字拡大でも項目と戻る操作が使える。
- lint・型チェック・既存翻訳テスト、日英と新しい配置のブラウザ確認、iOS exportを実施。実機確認と区別して記録する。

## 実装と検証記録

- 共通のSettingsActionをMap・Gacha右上へ追加し、Stackの設定画面に言語選択を移した。2行の言語名と選択チェックを表示し、Gacha下部のボタンは撤去した。
- 空のMapの本文が上部操作を覆う問題を、操作バーの重なりを明示して修正。非表示タブのMapが操作を受けないようにし、タブ移動後も設定ボタンをタップできることを確認した。
- lint・型チェック・既存Nodeテスト8ファイル、iOS exportが成功。
- WebでMap/Gacha右上の48点以上の入口、空のMapと進捗エラー時の到達、縦並びの選択項目、選択のチェック、日英タイトル、標準の戻る操作、再読み込み後の復元を確認。
- 設定から戻ると元のタブ・開封結果・Mapの選択プレビュー・カメラ位置が保持され、進捗JSONが同一であることを確認。保存失敗時の選択維持と再試行も成功。320×568の暗色・本文30pxの文字拡大でも項目が表示され、横はみ出しがない。
- 既存の日英の記事・参考資料・Map詳細、Mapの開封と位置復元・通常の開封演出、旧履歴から30教材までの追加取得と英語読書も回帰確認した。開封演出の終了確認はシートを閉じるアニメーションの完了を待つようにした。
- 実際のiPhoneでの新しい配置・標準ヘッダー・VoiceOverの確認は未実施。JSと既存アイコンの変更のみで、新たなネイティブビルドは不要。1.0.2のプレビュー更新として配信できる。
