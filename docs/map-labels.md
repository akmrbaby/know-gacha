# Mapの文字描画（#12）

## 目的と範囲

ズームで文字を引き伸ばさず、知識名・周辺語・関係名を読み取れるようにする。通常Mapと件数別デモの共通Canvasを対象とする。知識・関係・取得履歴・座標の保存形式は変更しない。

## 設計

- 文字を含むViewを拡大縮小する世界座標の親から外す。ノード中心は `camera + position × scale`、関係名は両端の画面座標の中点へ配置する。文字にscaleや逆scaleを適用しない。
- 知識名15pt、周辺語12pt、関係名10ptを維持し、OS文字拡大を許可する。折り返して表示し、固定高さで切り取らない。
- 知識名は縮小時も表示候補にする（重なり判定は適用する）。周辺語はscale 0.65で表示、0.5で非表示。関係名は1.1で表示、0.9で非表示。境界のちらつきを避ける。
- 選択中は対象と直接接続する知識・周辺語・関係名を優先し、それ以外の補助ラベルを隠す。表示枠の確保順は選択対象→接続先ノード→接続関係→その他の知識名→周辺語→その他の関係名。同順位では元のデータ順を維持する。
- 各ラベルのonLayoutで取得した実測サイズから画面上の矩形を作り、4ptの間隔を確保する。重なる下位ラベルと画面外のラベルは非表示にする。128ptの空間グリッドで全ラベルの総当たり比較を避ける。候補の選別と重なり判定もUIスレッドで行う。大量表示の全体密度調整は#13と連携する。
- パン・ピンチ・フォーカス・ドラッグ中もSharedValueからUIスレッドで位置を算出し、フレームごとにReactを再描画しない。文字層は指操作を遮らず、既存の座標によるタップ判定を維持する。
- 新規ノードの出現は文字の拡大演出から分離し、150msのopacityだけを使う。ラベルの表示切り替えは即時とする。初期案の120msフェードは、重なり判定で非表示になった文字が残って重なることを避けるため採用しない。動きを減らす設定では出現も即時とする。
- ノードの丸は従来と同じ画面上の寸法 `元サイズ × min(1, 2.1 × scale)` を保つ。文字の親をscaleせず、丸のwidth/heightと記号のfontSizeを調整する。知識名は常に等倍にするため、丸の下の配置枠は画面上で固定する。タップ／ドラッグは既存の中心座標による判定と最小半径26ptを維持する。

## 受け入れ条件と検証

- 5・10件で、ズーム中と停止後に文字の親を含めscale変形がなく、ノード中心と線・ラベル位置が一致する。
- 選択・パン・ピンチ・直接ドラッグ・カメラ移動、表示境界と選択優先度を確認する。
- OS文字拡大・動きを減らす設定を確認する。
- lint・型チェックと関連する自動検証を実施する。
- iPhoneの修正前後の鮮明さ、描画負荷、端末・OS・実行形態を記録する。Web確認でiPhoneの解消を断定しない。

- Web（Chromium、390×844、動きを減らす設定）: 5・10件の画面内SVG、ドラッグ・パン・フォーカス時の線とノード中心の一致、ノード／関係選択と解除が通過。
- 既存の線テストは最初の線と最初のノードが同じ知識であると仮定していた。#8後の最初の線はエスノグラフィー→写真なので、対象ノードを名前で指定するよう修正した。

### 追加の実機確認手順

1. Gachaの開発用操作からデモを開き、5件と10件それぞれで縮小→ピンチ拡大→停止を行う。知識名・周辺語・関係名の鮮明さと出現順を確認する。
2. ノードを選択し、接続する周辺語と関係名が優先されることを確認する。関係そのものの選択でも名称が読めることを確認する。パン・ピンチ・ノードドラッグ・カメラフォーカス中にラベルが追従し、操作を遮らないことを確認する。
3. OSの文字を拡大し、「視差効果を減らす」を有効にして1・2を繰り返す。折り返し・重なり回避・選択した名称の読み取りを確認する。通常Mapへ戻っても操作できることを確認する。
4. 計測なしの操作感を先に記録し、デモの20秒計測でパン・ピンチ・ドラッグを実施してJSONを保存する。5・10件、実行形態、Expo Goバージョン、コード状態、文字拡大／動きを減らす設定を併記する。修正前後を比較する場合は条件をそろえる。[実機評価の制約](map-device-evaluation.md)に従い、UIコールバック間隔をGPU描画時間や入力遅延とは呼ばない。
