# 日本語・英語対応（2026-11-09）

## 実装前の設計

画面と現在の10教材・Mapの周辺概念／関係説明を日本語と英語で表示する。初回は端末の優先言語を採用し、日本語以外は英語へフォールバック。Gachaで日本語／Englishを手動選択でき、独立キーに保存する。履歴・ガチャ権利・知識ID・位置・参照URLは共通で、切替で再取得や初期化を起こさない。

日本語の原稿を基準に表示用カタログで翻訳する。UIの文言・数値を含むメッセージと、安定した知識IDに対応した英語原稿を分離して管理。独自教材の翻訳であり、参照先サイト自体の翻訳ではない。将来の校閲・用語統一を残し、機械的な翻訳完成を公開校閲済みとは扱わない。

参考文献は信頼できる原典を言語間で共通利用する。保存済みの題名とURLを保持し、リンク先言語を明示する。日本語資料を英語版から排除せず、英語の代替資料を無検証で差し替えない。現在の日本語リンクはNTTの光通信解説、英語はNobel Prize・Intel・MoMA・GOV.UK・Tate・V&A・Open Encyclopedia of Anthropology。未知の参照先は言語を推測しない。

SDK 58のexpo-localizationで端末の優先言語を取得し、version 1.0.2で新ビルドとruntimeVersionを分離。言語選択は起動時に復元し、起動演出は言語復元も考慮。OSの言語変更は次回起動に反映、手動選択を優先する。

検証: 日英10教材とMapの対応漏れ、残数／件数・読書・履歴・戻る表示・エラー・参考資料、手動切替と再起動、権利と履歴維持、保存失敗、英語端末と未対応言語、暗色／小画面、lint・型チェックと既存テスト、iOS exportを確認する。実機の言語検出は新ビルドで確認する。

## 実装済み

- Gacha下部に「言語 / Language」と日本語・Englishの選択を追加。初回の優先言語はexpo-localization、手動選択は`knowgacha.locale.v1`へ保存する。読み込み失敗は端末言語、保存失敗は直前の言語を維持してエラーを表示する。
- UI・見出し・ボタン・読書・履歴・アクセシビリティラベル・エラーと検証メニューを翻訳。10教材・7周辺概念・18関係の英語原稿を安定したIDで対応付け、数値を含むメッセージを個別に整形する。知識ID、進捗の保存形式とキー、ガチャ付与、Mapの位置保存は変更しない。
- 参照元の題名とURLを共用し、確認した参照先にだけ資料の言語を表示する。日本語の参照元も英語画面で表示する。
- 読書からMapへ移動する内部リンクはホームの`/`へ直接接続し、選んだ知識のプレビューまで表示する。古い`/graph`リンクの互換リダイレクトは残す。
- 英語の戻る操作は標準の矢印表示を使う。長い英語の教材名と戻るラベルの幅競合を避けるためで、日本語は「戻る」を維持する。
- SDK 58互換の`expo-localization ~58.0.5`を追加。iOSの対応言語はja/en、RTLは無効。ネイティブ変更を含むためアプリとruntimeVersionは1.0.2とする。
