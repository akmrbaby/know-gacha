# 配色の調整（2026-11-09、実装前）

ユーザー了承の方向: 明るいアイボリー・深いティール・コーラルを軸に、使いやすさと興味を引く印象を両立する。

背景は黄みを抑えたアイボリー、本文は深いティール、主ボタンと選択タブはコーラル。Mapの知識はティール・紫・琥珀色に統一し、色に加えて既存の名前・記号・選択輪郭を維持する。背景のドットと通常線は控えめにする。カプセルも新しい配色に合わせ、暗色時も帯の文字を読みやすくする。

色を純粋なトークンファイルへ集約し、データ／デモ／UIで同じ知識色を使う。レイアウト・権利管理・保存データ・Mapの操作は変更しない。

主要な本文・補足・主ボタン文字の平面色同士はコントラスト比4.5:1以上を確認する。装飾・不透明度を下げた非選択要素・押下／無効状態を含む完全なアクセシビリティ認証は主張しない。明色／暗色のGacha・MapをWebで比較し、既存の操作テスト、lint・型チェックを実行する。iPhoneの実際の見え方は配信後に確認する。

## 実装・確認結果
- 明色: 背景`#FAF9F5`、本文`#153D3A`、コーラル`#C64B34`。暗色: 深い緑の背景`#122420`、本文`#F3F7F3`、コーラル`#FF9C80`。
- 知識: ティール`#197B78`、紫`#8060B0`、琥珀`#9B6514`。記号は白。星形記号はテキスト表示を要求し、絵文字の固有色が配色に混ざるのを抑える。
- 平面色の計算結果: 明色の本文11.32、補足5.71、主ボタン4.71、カプセル帯11.93。暗色は順に14.94、9.58、7.59、13.12。知識の白い記号は各色で5.07／4.98／4.92。小数値はコントラスト比。
- lint・型チェック・既存7テストファイル成功。WebでGachaの開封・読む・再訪・Map・デモ・全件取得と暗色／大きい文字、10件のMapの選択／中央表示／詳細／背景パン／履歴・位置復元が成功。明色／暗色のGachaとMapの画像を取得し、目視で確認。
- 色と描画の変更のみ。iPhoneの実際の発色・明るい屋外等での見え方は未確認。
