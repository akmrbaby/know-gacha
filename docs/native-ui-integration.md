# #9 ネイティブUIの実画面統合

## 目的・前提
#7の `4f02f60`（線の視認性・選択強調まで）を取り込んだ#9のworktreeで、UI基盤を実画面へ適用する。先行設計は[native-ui-foundation.md](native-ui-foundation.md)。#8のMapホーム化は別Issueとして残し、タブ順序と開封回数・保存形式は維持する。

## 範囲・画面・操作（実装済み・実機未検証）
- Map: 大きいコピーと文字記号の操作を整理し、件数と一覧への操作バー、拡大・縮小・全体表示をアイコンで提供する。Canvasの配置・カメラ・指操作ロジックは引き継ぐ。
- 詳細・一覧: @expo/ui BottomSheetのhalf/fullと標準の指操作を利用する。シートはモーダルとして背景Mapへの入力を遮断し、閉じると探索を再開する。独自のドラッグ判定を削除し、Mapとのジェスチャー競合を避ける。本文はスクロール、関連語・関係は行形式で辿る。閉じるボタンも用意する。
- Gacha: 過剰なキャッチコピーと縦並び操作を減らし、今日の一語と開封状態を中心にする。開封演出・取得制限は維持する。
- 読書・履歴: 不要なカードを減らし、本文・区切りと行で情報を整理する。
- アイコン: expo-symbolsでiOSはSF Symbols、Android/WebはMaterial Symbolsを明示。文字記号によるタブ・操作アイコンを置き換える。
- 押下: 色・透明度で即座に反応。選択・シートを開く操作に限定して控えめな触覚を付ける。ドラッグやズームの各フレームでは鳴らさない。触覚失敗で操作を中断しない。
- ガラス: expo-glass-effectの実行時／ビルド時の対応判定が両方trueかつ透明度を下げる設定がoffの時、Mapの操作バーでのみ利用。それ以外は同じ位置の不透明面。本文にガラスは使わない。
- 明暗: OSに従う配色とstatus bar、ナビゲーション・本文を揃える。GraphCanvasは意味を持つノード色を保持し、背景・ラベル・線の中間色をテーマに対応させる。
- アクセシビリティ: 48点以上の操作領域、アイコン操作名、見出し、選択・処理中状態、文字拡大、明示的な閉じる操作。独自の演出は動きを減らす設定で抑制し、シートはOS標準の動作に従う。

## データ・永続化
開封の保存キー・モデル・1日1回制限・履歴は変更しない。検索・保存機能はこのIssueでは追加しない。画面内の選択・開閉のみ管理する。UI用のネイティブ依存をSDK 58互換で追加する。ネイティブディレクトリは生成しない。

## 受け入れ条件
- 0件／取得済み／本日取得済みで、主要操作が分かり、開封・読書・Map・履歴の既存導線が利用できる。
- Mapのノード・線・一覧から詳細を開き、関連語・関係へ移動し、閉じて探索を続けられる。
- シート内スクロール／段階的展開／閉じる指操作は標準部品へ委譲し、背後のMapを誤操作しない。
- ガラス有効／無効のどちらでも操作が読める。暗色・文字拡大でも主要操作が欠けない。
- lint・型チェック・既存のグラフ／保存テストを通す。Webで開封・探索の流れと明暗・文字拡大を検証する。
- 実装・Web確認とiOS/Androidの実機確認を区別して記録する。触覚・シートの感触・ガラスの見え方を静止画だけで検証済みとしない。

## 実装と設計の補足
- Mapの一覧と詳細は1つのAppSheetを共有する。内容の切替で別モーダルを重ねない。閉じる際はisPresentedをfalseにし、標準の終了動作を使えるようコンポーネントを保持する。
- 詳細から読書など画面遷移する際はシートを閉じる。旧仕様の「戻ると選択シートも復元」から変更し、隠れたタブ上にモーダルが残ることを避けた。カメラはCanvasを再マウントせず保持する。
- SDK 58.0.27のBottomSheetはiOS/Androidで内部にHostを持つことを導入ソースで確認した。RNHostView内にReact Nativeのスクロール本文を置く。half/fullはAndroidの標準の2段階に合わせる。
- テーマの定義元をsrc/theme.tsへ集約。Capsuleの絵柄は固定色を維持し、画面・本文・操作部品はOS配色へ追従する。Materialアイコンのフォントは依存パッケージ内の資産を利用する。
- 開封時の触覚をCapsuleのタイマーから保存成功時へ移し、1操作で二重に鳴らさない。自動カメラ移動やズーム操作には触覚を付けない。
- ガラスは初期状態を不透明にし、iOSで透明度設定の取得後に切り替える。Android/WebはこのiOS専用APIを呼ばない。取得失敗時も不透明を保つ。
- 動きを減らす設定では既存の開封・Canvas演出を抑え、画面遷移はnoneにする。BottomSheetは標準部品のアクセシビリティ動作に委譲する。
