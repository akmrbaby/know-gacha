# 公開用の初期3回と30語の校閲原稿（2026-11-17）

状態: 実装・自動テスト・Web確認・iOS export済み。実機での初期3回の確認とユーザーによる教材校閲は未実施。

## 初期回数

ユーザーが初期合計3回を指定。新規ユーザーは初回特典2回＋初日の日次分1回で開始する。初回特典は繰り返し付与せず、日次分は引き続き毎日増えて繰り越せる。初期3回を使い切った翌日は1回、0回から3日経過したら3回を開封できる。

保存済みv2/v3のinitialBonus・履歴・日次開始日を保ち、既存の9回付与を2回へ減らさない。v1には付与数の記録がないので、従来の移行ルールである特典9回を維持する。設定の明示的な初期化を実行した場合のみ、新しい初期3回でやり直す。

UI・バッジは既存の残高計算を使い、検証メニューの回数表示も共通定数へ追従する。ネイティブ依存・保存形式・runtimeVersionは変更しない。

## 校閲

ユーザーが30語の校閲を行うため、現在の抽選対象30語の日英の名称・分野・問い・概要・全文と、アプリに表示する参考資料を一つのMarkdownへ書き出す。旧履歴用4語は抽選対象でないので除外する。目次と語ごとの修正メモ欄を付ける。

校閲原稿の準備と、内容の正しさを検証する校閲自体を区別する。本文は変更せず、校閲済みの表示やApp Store向けの品質宣言も変更しない。原稿はデータソースから再生成可能にする。再生成するとメモ欄も初期化されるため、修正メモは別ファイルに残す手順を案内する。

## 検証
