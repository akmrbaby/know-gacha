# Mapをホームにする（#8）

## 目的・範囲
起動から開封、つながりの探索を一続きにする。既存の取得回数制限・履歴と共有グラフを維持する。旧設計のGacha初期画面を置き換える。

## 画面と操作（実装済み・ユーザー実機確認済み）
- `/` をMap、既存のGachaを補助タブにする。旧 `/graph` はMapに転送する。
- 0件では最初の開封を案内する。取得済みではMap上に今日の開封ボタンを置き、開封済みなら今日の知識を再選択できる。全件取得後も探索できる。
- Map内のシートで開封演出を表示し、終了すると新しいノードを選択する。関連ノードと線から説明へ進む。
- ノードの下部シートは半画面から引き上げ可能。全文と関連語を同じシートで読み、閉じて探索を続ける。
- 最小導線は既存の一覧と開封履歴、および最新の取得知識への再訪。3語の試作では検索は一覧で代替。任意保存は取得済みとの違いが薄いため見送る。検索・保存・最近の関係の専用一覧は後続候補。

## データと永続化（実装済み・ユーザー実機確認済み）
通常教材には共有概念「写真」を追加する。エスノグラフィーでは調査・記録の方法の一つ、シュルレアリスムでは表現媒体の一つとして別々の出典付き関係を持つ。同一ノードを再利用し、片方だけ取得した時はもう片方の未取得教材を表示しない。写真の利用が両分野で同じ目的を持つことや直接の影響関係を意味しない。光電融合へは無理に接続せず、関係がない取得でも探索を続けられるようにする。取得可能な3語・保存IDは変更しない。

進捗v1と保存成功後に取得を確定する動作を維持する。Mapのパン・倍率は画面復帰時に保持し、再起動時にも最後の位置を復元する。端末サイズ変更では画面中心を基準に補正する。初回は全体表示、明示的なノード選択・全体表示で位置を更新する。位置の保存失敗は履歴に影響させない。開封演出と詳細は一つのネイティブシート内で内容を切り替え、別シート同士の同時開閉を避ける。演出を閉じた時は新ノードへカメラを寄せてMapへ戻し、演出完了／スキップ時は同じシートで詳細を表示する。

## 受け入れ条件・検証
- 0件・未開封・本日取得済み・全件取得済みで次の行動を示す。
- Map内で開封し、新ノードと関係を確認できる。
- 半画面の解説から全文・関連知識へ進み、閉じてMapに戻れる。
- 復帰・再起動で位置を保持する。
- 1日1回と既存履歴を維持し、開封できない日も探索できる。
- lint・型チェックと取得制限の自動検証を通す。

5. 当日の再取得ができず、開発用の翌日操作では新しい語を取得できること、3語取得後も探索できることを確認する。
