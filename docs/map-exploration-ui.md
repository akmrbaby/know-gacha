# Mapの探索UI整理（2026-11-09、実装前）

ユーザーが改善案1・2・3を指定。Mapの常設案内を小さくし、ノード／線のタップでカメラを動かさず、選択した知識のつながりを読みやすくする。

- 下部の開封案内カード・履歴行を撤去。残り回数の小さなボタンとズーム操作を1列に配置。履歴は既存一覧の末尾へ。残り回数ボタンは従来のMap内開封を維持する。
- ノード、線、一覧、関連知識の選択はカメラを動かさない。明示的な「中央に表示」と全体／ズームだけで移動する。外部の「Mapで見る」と新しい開封結果への移動は、対象を見たいという明示的な意図として引き続き対象へフォーカスする。
- 選択時はモーダルを開かず、下部に名前・短い紹介・近隣への導線・詳細／中央ボタンを表示。選択中も背景のパン／ピンチと別ノードの選択を可能にする。上スワイプまたは詳細ボタンで既存の標準half/fullシートを開く。詳細を閉じるとプレビューへ戻り、プレビューの閉じる／背景タップで選択解除する。
- 選択点と直接接続点を明瞭に、無関係な点と線を薄く表示。ノード名と関係名は選択近傍を優先し、線選択では両端を強調。文字は画面座標・重なり回避を維持。デモ側も同じCanvasの強調改善を利用するが通常Mapのプレビュー変更が対象。
- 検索・描画エンジン・保存形式・取得権利は変更しない。
